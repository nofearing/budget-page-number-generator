# 預決算書頁碼生成器（Budget Page Number Generator）

一款專為預算書、決算書及其他多表件裝訂文件設計的頁碼編排工具。

採用 **HTML + JavaScript** 開發，可直接在瀏覽器中執行，無須安裝 Excel、Python 或其他軟體。

透過批次讀取 PDF、計算表件起迄頁碼及提示空白頁插入位置，減少人工統計頁數與調整目錄的工作。

## ✨ 主要功能

### 1. 批次匯入 PDF 表件
- 使用者自行選取排版資料夾。
- 自動讀取資料夾中的 PDF 檔案。
- 依檔名建立表件清單並排序。
- 自動偵測各 PDF 的頁數。
- PDF 頁數讀取失敗時顯示警示，避免錯誤計算。

### 2. 自動計算頁碼
- 自動計算各表件的起頁及迄頁。
- 支援單頁及多頁表件。
- 支援對開表件從偶數編頁開始的規則。
- 自動檢查需要插入空白頁的位置。
- 可依建議批次新增空白頁項目。

### 3. 特殊頁面處理
支援三種頁面類型：

| 頁面類型 | 是否編頁 | 說明 |
|---|---|---|
| 一般表件 | 是 | 依實際 PDF 頁數累計 |
| 空白頁 | 是 | 用於調整對開位置，實際頁面印有「本頁空白」 |
| 分隔頁 | 否 | 獨立印刷、裝訂，不列入 PDF 合併成品 |

分隔頁通常以不同顏色紙張印製，實體裝訂占用一張雙面紙。

### 4. 自動生成目錄
提供兩種目錄顯示版本：

**版本一：完整編排目錄**
- 顯示所有一般表件、空白頁及分隔頁。
- 一般表件顯示起迄頁碼。
- 空白頁以橘黃色塊標示。
- 分隔頁以粉紅色色塊標示。

**版本二：精簡目錄**
- 顯示一般表件及分隔頁。
- 不顯示空白頁項目。
- 保留原始頁碼計算結果。

頁碼格式範例：

```text
總說明………………………………1～9
歲入來源別決算表…………………12～15
歲出政事別決算表…………………16～17
```

支援目錄預覽及透過瀏覽器列印、另存 PDF。

### 5. 專案儲存與資料匯出
- 支援 JSON 專案儲存及重新載入。
- 支援 CSV 編排清單匯出。
- 可手動新增、修改、刪除及調整表件順序。
- 不必每次重新建立表件資料。

### 6. 表件排序與編排管理

提供多種表件編排方式，方便處理大量 PDF 表件：

| 操作方式 | 功能說明 |
|---|---|
| 拖曳排序 | 按住表件左側的「⠿」把手，直接拖曳至目標位置 |
| 指定項次 | 點選「移至…」，輸入目標項次即可完成移動 |
| 指定位置插入 | 點選「＋插入…」，在目前表件前新增項目 |
| 自動重算頁碼 | 表件順序變動後，重新計算各表件起迄頁碼 |
| 空白頁重新生成 | 依最新編排順序重新安排必要的空白頁 |

支援插入的項目包括：
- 一般表件
- 分隔頁
- 本頁空白

使用者可先匯入 PDF 資料夾，再依實際裝訂需求調整順序、設定對開表件及加入分隔頁。


## 🚀 使用方法

1. **開啟工具**：下載 `index.html`，使用 Chrome 或 Edge 開啟；也可透過 GitHub Pages 使用。
2. **匯入 PDF**：點選「選取排版資料夾」，自動讀取表件檔名與頁數。
3. **調整表件順序**：使用拖曳把手或「移至…」功能，排列各項表件。
4. **插入特殊頁面**：透過「＋插入…」功能，在適當位置加入分隔頁或其他表件。
5. **設定對開表件**：指定需要從偶數編頁開始的表件。
6. **重新生成空白頁**：依最新表件順序及頁數，重新計算並補入必要的「本頁空白」項目。
7. **檢查編頁結果**：確認各表件起迄頁碼、空白頁配置及檢核訊息。
8. **生成目錄**：點選「生成目錄」，選擇完整版本或精簡版本，列印或另存 PDF。
9. **準備排版檔案**：依編排結果，在實際排版資料夾中放入所需的「本頁空白」PDF。
10. **合併及送印**：使用獨立的 PDF 合併工具產生送印檔案；分隔頁另外交由印刷廠製作並裝訂。

### 專案保存

建議在完成編排後匯出 JSON 專案檔，保留表件順序、頁碼設定及特殊頁面配置，以便日後修改或重新編排。

> **注意：** 本工具主要負責頁碼規劃與目錄生成。表件清單中的「本頁空白」是編排項目，不代表程式已經在排版資料夾中建立實際 PDF 檔案。

## 📁 建議資料夾結構

```text
預決算書/
├── 排版/
│   ├── 01_總說明.pdf
│   ├── 02_本頁空白.pdf
│   ├── 03_歲入來源別決算表.pdf
│   └── 04_歲出政事別決算表.pdf
│
└── 送印/
    └── 決算書_合併.pdf
```

建議使用檔名前置編號，確保檔案排序符合預期。

## ⚙️ 技術說明

- 開發技術：HTML、CSS、JavaScript
- 執行環境：Google Chrome、Microsoft Edge
- 使用方式：單一 HTML 檔案
- 支援離線操作
- 不需要後端伺服器

PDF 檔案由使用者選取後於本機瀏覽器處理，無須上傳至遠端伺服器。

**注意事項：**
- 部分特殊 PDF 結構可能無法正確辨識頁數，請依程式警示人工核對。
- 首次匯入資料夾後，仍須確認對開設定與分隔頁位置。
- 建議定期匯出 JSON 專案檔，以保留編排設定。
- 正式送印前，應再次核對目錄頁碼與合併後的 PDF。

## 📖 開發緣起

預決算書通常包含數十份獨立表件，部分表件需要左右對開，章節之間也可能設有獨立印製的分隔頁。

傳統編排方式需要逐一查閱 PDF 頁數、手動計算起迄頁碼，再依照裝訂要求補入空白頁。只要其中一份表件的頁數改變，後續目錄就可能需要重新計算。

本工具最初以 Excel VBA 開發，後續改寫為互動式 HTML，目的是減少重複輸入、降低頁碼計算錯誤，並讓整個排版過程更容易檢查與維護。
